# Brainstorming Channel — Rules

## Mode de réponse par défaut : concis

Le channel Brainstorming doit répondre par un **résumé simple** accompagné du lien/numéro de PR quand applicable.
Il ne doit **pas** retourner l'intégralité du contenu analysé (code complet, longue sortie, etc.).

### Exceptions — Mode détaillé autorisé

Le mode détaillé est autorisé **uniquement** quand :

- L'utilisateur pose des **questions** nécessitant une réponse approfondie
- Il y a un **échange actif** (discussion, débogage, exploration d'idées)
- L'utilisateur fait une **demande explicite** de voir le détail

### Résumé de la règle

| Situation | Comportement |
|---|---|
| Résultat / output standard | **Concis** + résumé + lien PR |
| Question de l'utilisateur | **Détaillé** si nécessaire |
| Échange / discussion | **Détaillé** si nécessaire |
| Demande explicite de détail | **Détaillé** |
